Shapes

Pick the shape that the show draws on. Each shape is one SVG file in the shapes folder. "Preview" opens the normal view. "Projector" opens the full-frame picture for the projector, and the show starts by itself.

Add a shape

  1. Put an SVG file in the shapes folder. Example: shapes/my-shape.svg
  2. Open index.html?shape=my-shape
  3. To tune it, or to show it on this page, add an entry in shapes/shapes.js.
